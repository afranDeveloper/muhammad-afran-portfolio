# Muhammad Afran — Portfolio

Professional Next.js portfolio for Muhammad Afran, Senior Unity Developer — Games, Simulators & AR/VR.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

Push this folder to GitHub, import the repository in Vercel, and deploy. No environment variables are required.

Before publishing, replace `your-email@example.com` in `app/page.tsx` with your real contact email and add your project screenshots/videos.
